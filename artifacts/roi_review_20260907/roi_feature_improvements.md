# ROI 주변 특징점 추출 개선 — 2026-09-08

로컬 소스에 ROI 전용 SIFT 정합을 추가했다. CAM4 저장 JPG에서는 아래쪽 ROI 끝의 대응점이 여전히 부족하므로 보정 성공으로 판단하지 않는다. 단말 배포·설정 변경은 하지 않았다.

## 변경 내용

- BASE ROI의 모든 선분 주변 120px 영역에서 특징점을 별도 추출한다. 독립 선분 사이에는 가상의 연결선을 만들지 않는다.
- 80px 셀마다 최대 60개 특징점을 배정한다. 패딩을 포함한 셀에서 낮은 대비의 특징도 검출하고, descriptor는 원본 영상 좌표에서 계산한다. 전체 descriptor 예산은 영상당 3,000개다.
- 현재 영상에서는 전체 셀을 탐색한다. 불안정한 초기 변환으로 탐색 범위를 제한하지 않는다.
- 동일 위치의 방향·스케일 중복과 동일 목적지에 몰리는 대응점을 3px 기준으로 제거한다.
- 거리 기준은 640px 대비 입력 해상도에 비례한다. 매칭 비율 0.7, 양방향 검사, 최소 인라이어 15개, 비율 0.5, ROI 주변 근거·화면 경계·변환 크기 검증은 유지한다.
- ROI 전용 SIFT가 실패하면 전역 SIFT와 ORB도 같은 기준으로 검증한다.

## 검증 결과

| 입력 | ROI 전용 결과 | 최종 결과 |
|---|---|---|
| CAM4 BASE → suspect JPG | 고유 대응점 3개, 변환 계산 안 함 | 보류 |
| CAM4 BASE → confirm JPG | 인라이어 4개, 아래쪽 끝 주변 0개 | 보류 |
| 약한 ROI 질감 + 강한 천장 질감 합성 영상, 원근 변환 | 인라이어 287개, 양 끝 주변 각각 85개 | 통과, ROI 최대 오차 0.025px 미만 |
| 같은 합성 영상의 전역 SIFT/ORB 경로 | ROI 주변 대응점 0개 | 보류 |

합성 영상에는 알려진 정답 변환이 있다. CAM4에는 실측 정답 좌표가 없으며, 저장 JPG에 대해 정확도가 개선됐다고 주장할 근거는 없다. 생성된 대응점 그림의 REJECTED 변환은 진단용이며 적용할 ROI가 아니다.

회귀 테스트 24개 실행: 23개 통과, 체크아웃에 없는 legacy danmal 소스 관련 1개 건너뜀. 실제 특징점 정합, 원근 변화, ROI 가림, 무질감, 잘못된 보정 보류, 중복 제거, 독립 선분 마스크, 보정 적용/재시도 검증을 포함한다. `git diff --check` 통과.

이번 PC의 640×480 실행은 초기 실행 약 1.50초, 이후 CAM4 약 0.26초, 합성 ROI 정합 약 0.20초였다. 단말·고해상도 영상 성능은 측정하지 않았다.

## 재현

OpenCV와 NumPy가 설치된 Python에서 저장 자료와 합성 비교를 재현한다.

```powershell
python artifacts/roi_review_20260907/evaluate_roi_features.py
python -m unittest discover -s tests -p 'test_roi_auto_correct*.py'
```

원본 해상도 이미지가 확보되면 같은 스크립트로 재평가할 수 있다. `--lines`는 반드시 BASE 원본 픽셀 좌표를 사용한다. 아래 좌표는 640×480 CAM4 JPG에 해당한다.

```powershell
python artifacts/roi_review_20260907/evaluate_roi_features.py --base BASE.png --current CURRENT.png --lines '[[47,463],[37,268]]'
```

출력은 `roi_native_results.json`과 `roi_native_*.jpg`에 저장된다. 프로그램은 영상을 확대·축소하지 않는다. 현재 운영 소스의 보정 입력도 메모리 프레임 해상도를 유지하며, 저장 진단 JPG만 별도로 축소한다. 디코더가 이미 축소한 입력의 센서 원본 정보를 복원하는 기능은 아니다.

현재 작업 폴더에는 CAM4의 640×480 JPG만 있다. 실사 개선 여부를 판정하려면 해당 시점의 원본 해상도 BASE·현재 영상이 필요하다. 원본에서도 ROI를 가리는 물체나 반복 무늬로 대응점이 부족하면 자동 보정을 계속 보류해야 한다.
